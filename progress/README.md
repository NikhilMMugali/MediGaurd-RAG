# progress/

Working-state tracking for the MediGuard RAG build, separate from the top-level product docs in `docs/`.

- **PROGRESS.md** — phase checklist, latest completed work, latest commit, known issues, next task. Update this after every completed major stage.
- **TODO.md** — the concrete task backlog, grouped by phase.
- **DECISIONS.md** — non-obvious implementation choices and why they were made, so a later session doesn't have to re-derive them.

See the root [README.md](../README.md) for the project overview, setup instructions, and demo script.
